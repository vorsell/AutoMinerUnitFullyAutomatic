# Auto Miner Unit - Fully Automatic

A RimWorld 1.6 extension for **Auto Miner Unit** that adds an automatic launcher capable of finding compatible scanned targets, constructing mining pods, waiting for fuel, and launching without manual target selection.

It supports land and asteroid automation, configurable target strategies, fuel limits, status reporting, roof safety checks, duplicate-pod handling, and optional Rimefeller fuel-pipe integration.
